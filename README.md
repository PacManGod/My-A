# Propuesta de novio

Este es un proyecto de sitio web de amor y romance. El sitio web contiene varias páginas que describen diferentes aspectos de una relación amorosa.

## Estructura del Proyecto

El proyecto tiene la siguiente estructura de directorios:

Assets/ 
  audio/ 
  css/ 
    amarte.css 
    conocerte.css 
    home.css 
    inicio.css 
  img/
  Js/
    amarte.js 
    conocerte.js
    home.js
    inicio.js
  vid/
home.html 
  pages/ 
    amarte.html
    conocerte.html
    Inicio.html

## Cómo ejecutar el proyecto

Para ejecutar este proyecto, simplemente abre el archivo `home.html` en tu navegador.
